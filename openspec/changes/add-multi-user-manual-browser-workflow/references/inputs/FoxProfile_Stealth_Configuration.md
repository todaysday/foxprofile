# FoxProfile: настройки stealth

Для уже установленного FoxProfile на Oracle ARM64 и AMD x86-64 без GPU. Настройки одинаковые для обоих серверов.

## 1. Режим запуска

В окружении сервиса FoxProfile:

```dotenv
FOXPROFILE_HEADLESS=virtual
```

Всегда запускать браузеры в этом режиме — и для агента, и для ручного доступа. Не переключать на `headless=True`. Изменение применяется при следующем запуске браузера.

## 2. Настройки профиля

| Настройка | Что сделать |
|---|---|
| `humanize=True` | Уже включён в `runner.py`. Оставить. |
| Fingerprint | Использовать сохранённый FoxProfile. Не генерировать заново при каждом запуске. |
| Cookies и данные | Сохранять в отдельной постоянной директории каждого профиля. |
| Прокси | Закрепить за профилем, а не за рабочим слотом. Не менять при открытии noVNC. |
| Часовой пояс и язык | Использовать штатный GeoIP через прокси либо сохранённые настройки профиля. Не менять случайно между запусками. |
| ОС профиля | Для новых профилей выбрать Linux. Существующие массово не переделывать. |
| WebGL | Оставить включённым. Не прописывать выдуманную видеокарту. |
| Canvas | Оставить штатные настройки Camoufox. Не добавлять принудительно `canvas_noise=True/False`. |

Не добавлять сверху JS-подмены UA, Canvas, шрифтов и `navigator.webdriver`. Отдельный генератор движений мыши тоже не нужен.

## 3. Экран и noVNC

Для новых профилей можно взять экран **1366×768**, если окно браузера помещается целиком. Размеры сохранять между запусками, а не подгонять под экран телефона.

В клиенте noVNC:

```javascript
rfb.scaleViewport = true;   // Масштабировать изображение у пользователя.
rfb.resizeSession = false;  // Не менять разрешение сервера.
```

Подключать noVNC к **существующему дисплею выбранного браузера**. Не перезапускать браузер и не менять fingerprint. «Вернуться назад» только закрывает noVNC; агенту пользователь сам сообщает «готово».

## 4. Проверить на одном профиле каждого сервера

1. Открыть [проверку IP](https://browserleaks.com/ip) и [WebRTC](https://browserleaks.com/webrtc) внутри профиля: должен использоваться прокси, публичный IP сервера не должен раскрываться.
2. Закрыть и снова открыть профиль: вход в аккаунт и сохранённый fingerprint должны остаться.
3. Перейти в noVNC и обратно: тот же браузер, вкладки и размеры экрана; клики работают.

Если проверки проходят, дополнительных stealth-патчей не делать. Это не гарантия отсутствия капч.
